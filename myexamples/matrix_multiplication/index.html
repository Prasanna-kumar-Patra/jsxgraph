  • Vector w (Green): y-coordinate transformation

Transformed Vectors

  • Result after matrix multiplication
  • v' (Red): Transformed vector v
  • w' (Green): Transformed vector w
  • Controlled by matrix values (a, b, c, d)

How to Use This Interactive Tool

  1. Observe the Original Vectors
    • Look at the left board showing vectors v (red) and w (green)
    • These represent the starting positions before transformation
  2. Understand the Matrix Controls
    • Use the sliders to change matrix values (a, b, c, d)
    • Each value affects how the vectors transform
  3. Watch the Transformation
    • See how the vectors change in real-time in the right board
    • Notice how different matrix values create different transformations
  4. Experiment and Learn
    • Try different matrix combinations
    • Observe how each element affects the transformation
    • Understand the relationship between matrix values and vector changes
