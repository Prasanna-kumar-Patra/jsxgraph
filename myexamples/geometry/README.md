# JSXGraph Geometry Application

A GeoGebra-like geometry application built using JSXGraph library.

## Features

- Interactive geometry board with grid and axes
- Basic geometric construction tools:
  - Point creation
  - Line and segment drawing
  - Circle construction
  - Polygon creation
- Zoom and pan controls
- Fullscreen mode
- Responsive design

## Setup

1. The application is built to run offline. Simply open the `index.html` file in a modern web browser.
2. All dependencies are included via CDN but can be downloaded for completely offline use.

## Usage

1. Select a tool from the toolbar at the bottom of the screen
2. Click on the canvas to create geometric objects
3. Use the utility buttons on the right for zooming and view control
4. Toggle the sidebar using the menu button for additional options

## Dependencies

- JSXGraph v1.5.0 (included via CDN)

## Browser Support

The application works best in modern browsers that support ES6+ JavaScript features.
